Java Map Interface

विवरण

  • Key-Value pairs store करता है
  • Keys unique होते हैं, values duplicate हो सकते हैं
  • Collection interface का हिस्सा नहीं → सीधे Iterable नहीं
  • for-each loop सीधे Map पर नहीं चलता

मुख्य Implementing Classes

  1. HashMap - Unordered, fastest, null key/value allowed
  2. LinkedHashMap - Insertion order maintain करता है
  3. TreeMap - Keys को sorted रखता है (natural order या Comparator)

Iteration के तरीके

import java.util.*;

Map<Integer, String> map = new HashMap<>();
map.put(1, "One");
map.put(2, "Two");
map.put(3, "Three");

// 1. Keys पर loop
for (Integer key : map.keySet()) {
    System.out.println(key + " -> " + map.get(key));
}

// 2. Values पर loop
for (String value : map.values()) {
    System.out.println(value);
}

// 3. EntrySet पर (सबसे recommended)
for (Map.Entry<Integer, String> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " -> " + entry.getValue());
}

// 4. Java 8+ forEach method
map.forEach((k, v) -> System.out.println(k + " -> " + v));

नोट

HashMap, LinkedHashMap और TreeMap में ऊपर के सभी iteration तरीके एक समान काम करते हैं।
